# greencup-backend  
EcoCrew's GreenCup Project - Backend Repository  

### 한글

## 시작하기  
이 원격 저장소를 로컬 저장소에 클론하려면 아래 과정대로 하시면 됩니다.  
  
### 1. 프로젝트 루트 디렉토리로 이동  
```cmd
cd d:\GreenCup  
```
### 2. 백엔드 원격 저장소 클론  
```cmd
git clone https://github.com/Eco-crew/greencup-backend.git  
```
### 3. 클론 후 디렉토리 구조  
```cmd
d:\GreenCup  
        └─ greencup-backend (d:\GreenCup\greencup-backend)  
```

### English  
  
## Getting Started  
Follow the steps below to clone the repositories to your local machine.  

### 1. Navigate to the project root directory  
```cmd
cd d:\GreenCup  
```
### 2. Clone the backend repository
```cmd
git clone https://github.com/Eco-crew/greencup-backend.git  
```
### 3. Resulting directory structure  
```cmd
d:\GreenCup  
        └─ greencup-backend (d:\GreenCup\greencup-backend)  
```
